# HA-Lymow

Home Assistant custom integration scaffold for Lymow.

Installation (development):

1. Copy the `custom_components/lymow` folder into your Home Assistant `config/custom_components` folder.
2. Restart Home Assistant.
3. Configure the integration via Integrations -> + -> Lymow.

This scaffold provides a placeholder `LymowHub` and a simple `sensor` entity to be extended with real API calls.
